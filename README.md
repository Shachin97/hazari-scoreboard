# Hazari Scoreboard

A scoreboard for the Hazari card game. Plain HTML, CSS and JavaScript, with no build step.

## Put it online with GitHub Pages
1. Create a new public repository on GitHub, for example `hazari-scoreboard`.
2. Upload every file in this folder to the repository root.
3. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", choose `main` and `/ (root)`, then save.
4. After a minute your app is live at `https://<your-username>.github.io/hazari-scoreboard/`.

## Install it on a phone
- **Android (Chrome):** open the site and tap **Install app** in the header, or use the browser menu's "Install app".
- **iPhone (Safari):** tap Share, then **Add to Home Screen**.

The installed app works offline.

## What this copy stores
Games are saved in the browser on each device. **Share** creates a snapshot link that holds the game as it is now. Live sync between devices needs a backend such as Supabase.
